# Prompt: Find UI/UX Designer Jobs (1.5+ Years Experience) in Ahmedabad

## Prompt

> Search for **UI/UX Designer** job openings that are **currently hiring in Ahmedabad, Gujarat, India**.
>
> **Requirements to match:**
> - Role: UI/UX Designer (also accept closely related titles such as *UX Designer*, *UI Designer*, *Product Designer*, *Interaction Designer*, *Visual/Web Designer*).
> - Experience level: **1.5+ years** (include roles asking for 1–3 years or "1.5 to 3 years"; exclude senior/lead roles requiring 5+ years and pure fresher/0-experience roles).
> - Location: **Ahmedabad** (include on-site, hybrid, and remote roles open to Ahmedabad candidates).
> - Status: Actively hiring / recently posted (prefer jobs posted within the last 30 days).
>
> **For each matching job, return a table with:**
> 1. Job title
> 2. Company name
> 3. Location (and work mode: on-site / hybrid / remote)
> 4. Required experience
> 5. Key skills mentioned (e.g., Figma, Adobe XD, Sketch, wireframing, prototyping, user research)
> 6. Posted date
> 7. Salary range (if listed)
> 8. Direct application link
>
> Sort results by most recently posted first. Highlight the best-fit matches for a candidate with ~1.5–2 years of experience, and note if any listing looks like a fresher trap or requires far more experience than stated.

## How to use

- **With the Indeed connector:** run `search_jobs` with query `UI UX Designer`, location `Ahmedabad, Gujarat, India`, and filter results to roles requesting 1.5+ years of experience. Use `get_job_details` to expand promising matches.
- **General:** paste the prompt above into any job-search assistant that can browse or query job boards (Indeed, LinkedIn, Naukri, etc.).

| Field | Value |

| Core skills | Figma, Adobe XD, Sketch, wireframing, prototyping, user research |
